# Shared Bip motion update
The twelve 720px/60fps gesture clips come from the same original Bip model and procedural source as Companion and the Phone viewer. Wave, walk, jump, dance and antenna wiggle are explicit finite actions in both Kids' World/learning paths and arcade practice. Existing pause and reduced-motion preferences are preserved, and completion returns to idle.
The floss uses two-link arm positioning, outward elbow poles and a front/outer wrist path rather than sweeping a shoulder rotation through the body. Every hand/forearm triangle was checked against the torso bounding ellipsoid at 240fps. There is no claim of a general physics collision system.
Validation: 123 Node tests pass; all twelve MP4 files fully decode, have pinned SHA-256 digests in public/bip/gestures-v3/validation.json, and contain no audio. Production build passes. A fresh 390px browser session entered Kids' World, played the 5.2-second dance and had no horizontal overflow or JavaScript errors.
Editable source: scripts/bip-motion; canonical build/model: home-cloud-infra/bip-app/character-src. Rendering uses pinned Three.js 0.180.0 and esbuild 0.25.10, Playwright/Edge, and FFmpeg. No family accounts, Studio permissions, maths content or scores were changed.
